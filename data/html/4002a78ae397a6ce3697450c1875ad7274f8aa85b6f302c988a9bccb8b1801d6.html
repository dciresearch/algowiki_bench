Последовательная сложность [math]\displaystyle{ O(n^2) + O(k^3) }[/math] - на одну итерацию. [math]\displaystyle{ O(kn^2) }[/math] - суммарно.
Объём входных данных [math]\displaystyle{ n^2 + n + 1 }[/math], при экономии памяти сокращается до [math]\displaystyle{ \frac{n(n - 1)}{2} + n + 1 }[/math]

Ширина ярусно-параллельной формы [math]\displaystyle{ O(kn) }[/math]

Свойства и структура алгоритма

Общее описание алгоритма

Метод Ланцоша — процедура, применяемая для нахождения [math]\displaystyle{ k }[/math] собственных значений симметричной матрицы произвольного размера путём вычисления их приближений. Суть метода заключается в итеративном построении специальной матрицы [math]\displaystyle{ T_{j} }[/math], а затем вычислении её собственных значений и собственных векторов. Общее описание алгоритма можно найти, например, в книге [1].

Здесь мы рассмотрим сильно [math]\displaystyle{ x + y }[/math] упрощенный вариант алгоритма Ланцоша, который подразумевает отсутствие влияния ошибок округления на вычислительный процесс. На практике используются модификации алгоритма Ланцоша, обладающие устойчивостью и без этого допущения ( например, алгоритм Ланцоша с полной переортогонализацией ).

Математическое описание алгоритма

Математическое описание алгоритма Ланцоща для вычисления собственных значений симметричной матрицы А требует 1) математического описания метода Ланцоща для построения крыловского подпространства и 2) математического описания т.н. процедуры Рэлея-Ритца.

Метод Ланцоща для построения крыловского подпространства

Пусть дано уравнение [math]\displaystyle{ Ax = b }[/math], причём вектор [math]\displaystyle{ b }[/math] известен и имеется способ вычисления [math]\displaystyle{ Ax }[/math].

Вычислим [math]\displaystyle{ y_{1} = b }[/math] , [math]\displaystyle{ y_{2} = Ab }[/math], [math]\displaystyle{ y_{3} = A^{2}b }[/math],...,[math]\displaystyle{ y_{n} = A^{(n - 1)}b }[/math], где [math]\displaystyle{ n }[/math] - порядок матрицы [math]\displaystyle{ A }[/math]. Определим матрицу [math]\displaystyle{ K = [y_{1},...,y_{n}] }[/math].

Тогда [math]\displaystyle{ AK = [Ay_{1},...,Ay_{n - 1}, Ay_{n}] = [y_{2},...,y_{n},A^n{y_{1}}] }[/math]. В предположении, что матрица [math]\displaystyle{ K }[/math] - невырождена, можно вычислить вектор [math]\displaystyle{ c = -K^{-1}A^{ny_{1}} }[/math]. Поскольку первые [math]\displaystyle{ n - 1 }[/math] столбцов в [math]\displaystyle{ AK }[/math] совпадают с последними [math]\displaystyle{ n - 1 }[/math] столбцами в [math]\displaystyle{ K }[/math], то справедливо: [math]\displaystyle{ AK = K[e_{2},e_{3},...,e_{n},-c] = KC }[/math], то есть [math]\displaystyle{ K^{-1}AK = C }[/math], где [math]\displaystyle{ C }[/math] - верхняя хессенбергова матрица.

Заменим [math]\displaystyle{ K }[/math] ортогональной матрицей [math]\displaystyle{ Q }[/math] так, что при любом [math]\displaystyle{ k }[/math] линейные оболочки первых [math]\displaystyle{ k }[/math] столбцов в [math]\displaystyle{ K }[/math] и [math]\displaystyle{ Q }[/math] - одно и то же подпространство. Это подпространство называется крыловским и точно определяется как [math]\displaystyle{ \kappa_{k}(A, b) }[/math] - линейная оболочка векторов [math]\displaystyle{ b }[/math],[math]\displaystyle{ Ab }[/math],...,[math]\displaystyle{ A^{(k - 1)}b }[/math]. Суть алгоритма Ланцоша заключается в вычислении стольких первых столбцов в [math]\displaystyle{ Q }[/math], сколько необходимо для получения требуемого приближения к решению [math]\displaystyle{ Ax = b }[/math] ([math]\displaystyle{ Ax = {\lambda}x }[/math]).

Используем QR-разложение матрицы [math]\displaystyle{ K = QQ }[/math]
Тогда [math]\displaystyle{ K^{-1}AK = (R^{-1}Q^{T})A(QR) = C }[/math], откуда [math]\displaystyle{ Q^{T}AQ = RCR^{-1} = H }[/math]

Матрица [math]\displaystyle{ H }[/math] является верхней хессенберговой в силу того, что верхней хессенберговой является матрица [math]\displaystyle{ C }[/math], а матрицы [math]\displaystyle{ R }[/math] и [math]\displaystyle{ R^{-1} }[/math] - верхние треугольные.

Однако алгоритм Ланцоша подразумевает симметричность матрицы [math]\displaystyle{ A }[/math]. Положим [math]\displaystyle{ Q = [Q_{k}, Q_{u}] }[/math], где [math]\displaystyle{ Q_{k} = [q_{1},...,q_{k}] }[/math] и [math]\displaystyle{ Q_{u} = [q_{k+1},...,q_{n}] }[/math]. В итоге получается, что [math]\displaystyle{ H = Q^{T}AQ = [Q_{k},Q_{u}]^{T}A[Q_{k},Q_{u}] }[/math] Из симметричности [math]\displaystyle{ A }[/math], таким образом, следует симметричность и трехдиагональность матрицы [math]\displaystyle{ H = T }[/math]. Теперь можно вывести две основные формулы, используемые в методе Ланцоша:

  • [math]\displaystyle{ AQ_{j} = \beta_{j - 1}q_{j - 1} + \alpha_{j}q_{j} + \beta_{j}q_{j + 1} }[/math] - получается приравниванием столбцов [math]\displaystyle{ j }[/math] в обеих частях равенства [math]\displaystyle{ AQ = QT }[/math].
  • [math]\displaystyle{ q_{j}^{T}Aq_{j} = \alpha_{j} }[/math] - получается домножением обеих частей предыдущего соотношения на [math]\displaystyle{ q_{j}^{T} }[/math] и учетом ортогональности [math]\displaystyle{ Q }[/math].

Процедура Рэлея-Ритца

Пусть [math]\displaystyle{ Q = [Q_{k}, Q_{u}] }[/math] - произвольная ортогональная матрица порядка [math]\displaystyle{ n }[/math], причём [math]\displaystyle{ Q_{k} }[/math] и [math]\displaystyle{ Q_{u} }[/math] имеют размеры [math]\displaystyle{ nk }[/math] и [math]\displaystyle{ n(n - k) }[/math].

Пусть [math]\displaystyle{ T = Q^{T}AQ = [Q_{k},Q_{u}]^{T}A[Q_{k},Q_{u}] }[/math]. Обратим внимание, что в случае [math]\displaystyle{ k = 1 }[/math] выражение [math]\displaystyle{ T_{k} = Q_{k}^{T}AQ_{k} }[/math] - отношение Рэлея [math]\displaystyle{ \rho(Q_{1},A) }[/math], то есть число [math]\displaystyle{ (Q_{1}^{T}AQ_{1}) / (Q_{1}^{T}Q_{1}) }[/math]. Определим теперь суть процедуры Рэлея-Ритца:

  • Процедура Рэлея-Ритца - интерпретация собственных значений матрицы [math]\displaystyle{ T = Q^{T}AQ }[/math] как приближений к собственным значениям матрицы [math]\displaystyle{ A }[/math]. Эти приближения называются числами Ритца. Пусть [math]\displaystyle{ T_{k} = V{\lambda}V^{T} }[/math] - спектральное разложение матрицы [math]\displaystyle{ T_{k} }[/math]. Столбцы матрицы [math]\displaystyle{ Q_{k}V }[/math] рассматриваются как приближения к соответствующим собственным векторам и называются векторами Ритца.

Существует несколько важных фактов о процедуре Рэлея-Ритца, характеризующих получаемые приближения собственных значений матрицы [math]\displaystyle{ A }[/math].

  • Минимум величины [math]\displaystyle{ ||AQ_{k} - Q_{k}R||_{2} }[/math] по всем симметричным [math]\displaystyle{ k^2 }[/math] матрицам [math]\displaystyle{ R }[/math] достигается при [math]\displaystyle{ R = T_{k} }[/math]. При этом [math]\displaystyle{ ||AQ_{k} - Q_{k}R||_{2} = ||T_{ku}||_{2} }[/math]. Пусть [math]\displaystyle{ T_{k} = V{\lambda}V^{T} }[/math] - спектральное разложение матрицы [math]\displaystyle{ T_{k} }[/math]. Минимум величины [math]\displaystyle{ ||AP_{k} - P_{k}D||_{2} }[/math], когда [math]\displaystyle{ P_{k} }[/math] пробегает множество [math]\displaystyle{ nk }[/math] матрицы с ортонормированными столбцами, таких, что [math]\displaystyle{ span(P_{k}) = span(Q_{k}) }[/math], а [math]\displaystyle{ D }[/math] пробегает множество диагональных [math]\displaystyle{ k^2 }[/math] матриц также равен [math]\displaystyle{ ||T_{ku}||_{2} }[/math] и достигается для [math]\displaystyle{ P_{k} = Q_{k}V }[/math] и [math]\displaystyle{ D = \lambda }[/math].

Пусть [math]\displaystyle{ T_{k} }[/math], [math]\displaystyle{ T_{ku} }[/math], [math]\displaystyle{ Q_{k} }[/math] - те же самые матрицы. Пусть [math]\displaystyle{ T_{k} = V{\lambda}V^{T} }[/math] - всё то же спектральное разложение, причём [math]\displaystyle{ V = [v_{1},...,v_{k}] }[/math] - ортогональная матрица, а [math]\displaystyle{ \lambda = diag(\theta_{1},...,\theta_{k}) }[/math]. Тогда:

  • Найдутся [math]\displaystyle{ k }[/math] необязательно наибольших собственных значений [math]\displaystyle{ \alpha_{1},...,\alpha_{k} }[/math] матрицы [math]\displaystyle{ A }[/math], такие, что [math]\displaystyle{ |\theta_{i} - \alpha_{i}| \lt = ||T_{ku}||_{2} }[/math] для [math]\displaystyle{ i = 1,...,k }[/math]. Если [math]\displaystyle{ Q_{k} }[/math] вычислена методом Ланцоша,то правая часть этого выражения равняется [math]\displaystyle{ \beta_{k} }[/math], то есть единственному элементу блока [math]\displaystyle{ T_{ku} }[/math], который может быть отличен от нуля. Указанный эдемент находится в правом верхнем углу блока.
  • [math]\displaystyle{ ||A(Q_{k}v_{i}) - (Q_{k}v_{i})\theta_{i}||_{2} = ||T_{ku}v_{i}||_{2} }[/math]. Таким образом, разность между числом Ритца [math]\displaystyle{ \theta_{j} }[/math] и некоторым собственным значением [math]\displaystyle{ \alpha }[/math] матрицы [math]\displaystyle{ A }[/math] не превышает величины [math]\displaystyle{ ||T_{ku}v_{i}||_{2} }[/math], которая может быть много меньше, чем [math]\displaystyle{ ||T_{ku}||_{2} }[/math]. Если матрица [math]\displaystyle{ Q_{k} }[/math] вычислена алгоритмом Ланцоша, то эта величина равна [math]\displaystyle{ \beta_{k}|v_{i}(k)| }[/math], где [math]\displaystyle{ v_{i}(k) }[/math] - k-ая компонента вектора [math]\displaystyle{ v_{i} }[/math]. Таким образом, можно дещево вычислить норму невязки - левой части выражения, не выполняя ни одного умножения вектора на матрицы [math]\displaystyle{ Q_{k} }[/math] или [math]\displaystyle{ A }[/math].
  • Не имея информации о спектре матрицы [math]\displaystyle{ T_{u} }[/math], нельзя дать какую-либо содержательную оценку для погрешности в векторе Ритца [math]\displaystyle{ Q_{k}v_{i} }[/math]. Если известно, что [math]\displaystyle{ \theta_{j} }[/math] отделено расстоянием, не меньшим [math]\displaystyle{ g }[/math], от прочих собственных значений матриц [math]\displaystyle{ T_{k} }[/math], [math]\displaystyle{ T_{u} }[/math] и матрица [math]\displaystyle{ Q_{k} }[/math] вычислена алгоритмом Ланцоша, то угол [math]\displaystyle{ \theta }[/math] между [math]\displaystyle{ Q_{k}v_{i} }[/math] и точным собственным вектором [math]\displaystyle{ A }[/math] можно оценить формулой [math]\displaystyle{ \frac{1}{2}\sin{2\theta} \lt = \frac{b_{k}}{g} }[/math]

В алгоритме Ланцоша из ортонормированных векторов строится матрица [math]\displaystyle{ Q_{k} = [q_{1},...,q_{k}] }[/math] и в качестве приближенных собственных значений [math]\displaystyle{ A }[/math] принимаются числа Ритца - собственные значения симметричной трёхдиагональной матрицы [math]\displaystyle{ T_{k} = Q_{k}^{T}AQ_{k} }[/math].

Вычислительное ядро алгоритма

Вычислительное ядро алгоритма Ланцоща состоит в получении на каждой итерации очередного промежуточного вектора [math]\displaystyle{ z }[/math], получаемого путём умножения исходной матрицы [math]\displaystyle{ A }[/math] на вектор Ланцоша [math]\displaystyle{ q_{j} }[/math], полученный на предыдущей итерации.

Также при значениях [math]\displaystyle{ k }[/math], сопоставимых с [math]\displaystyle{ n }[/math], процедура вычисления собственных значений и собственных векторов симметричной трёхдиагональной матрицы по некоторому выбранному алгоритму подразумевает значительный объём расчётов и может считаться вычислительным ядром. Однако на практике метод используется прежде всего при малых [math]\displaystyle{ k }[/math].

Макроструктура алгоритма

Метод Ланцоша соединяет метод Ланцоша для построения крыловского подпространства в процедурой Рэлея-Ритца, подразумевающей вычисление собственных значений симметричной трёхдиагональной матрицы. Первая часть алгоритма представляет собой строго последовательные итерации, на каждой из которых вначале строится очередной столбец матрицы [math]\displaystyle{ Q_{j} }[/math] из первых [math]\displaystyle{ j }[/math] ортонормированных векторов Ланцоша и матрица [math]\displaystyle{ T_{j} = Q^T_{j}AQ_{j} }[/math] порядка [math]\displaystyle{ j }[/math]. Итерационный процесс завершается, когда [math]\displaystyle{ j = k }[/math]. Вторая часть алгоритма представляет собой поиск собственных значений и собственных векторов симметричной трёхдиагональной матрицы [math]\displaystyle{ T_{j} }[/math], что реализуется отдельным алгоритмом, на практике используется QR-алгоритм.

Особенность методов крыловского подпространства состоит в предположении, что матрица [math]\displaystyle{ A }[/math] доступна в виде "черного ящика", а именно подпрограммы, вычисляющей по заданному вектору [math]\displaystyle{ z }[/math] произведение [math]\displaystyle{ y = Az }[/math] (а также, возможно, произведение [math]\displaystyle{ y = A^{T}z }[/math], если матрица [math]\displaystyle{ A }[/math] несимметрична). Другими словами, прямой доступ к элементам матрицы и их изменение не используются, т.к.

  • Умножение матрицы на вектор - наиболее дешевая нетривиальная операция, которую можно проделать с разреженной матрицей: в случае разреженной [math]\displaystyle{ A }[/math], содержащей [math]\displaystyle{ m }[/math] ненулевых элементов, для матрично-векторного умножения нужны [math]\displaystyle{ m }[/math] скалярных умножений и не более [math]\displaystyle{ m }[/math] сложений.
  • [math]\displaystyle{ A }[/math] может быть не представлена в виде матрицы явно, а доступна именно через подпрограмму для вычисления произведений [math]\displaystyle{ Ax }[/math].

Таким образом, как QR-алгоритм поиска собственных значений, собственных векторов матрицы [math]\displaystyle{ T_{j} }[/math] и оценки погрешности в них результирующей трехдиагональной матрицы, так и умножение матрицы на вектор внутри каждой итерации могут быть рассмотрены в качестве отдельных макроопераций. Проблемой является то, что именно эти манипуляции порождают основную вычислительную сложность алгоритма. Поскольку матрица, к которой применяется QR-алгоритм, имеет порядок [math]\displaystyle{ k }[/math] и на практике бывает мала, сделаем допущение о плотности матрицы [math]\displaystyle{ A }[/math]. Тогда умножение этой матрицы на вектор внутри каждой итерации нужно будет реализовывать в рамках самого алгоритма. Еще одним важным замечанием является момент вычисления собственных значений матрицы [math]\displaystyle{ T_{j} }[/math]. Её собственные значения, полученные на итерации [math]\displaystyle{ p }[/math], никак не используются на итерации [math]\displaystyle{ p + 1 }[/math], поэтому целесообразно вынести эту процедуру за основной цикл. Однако на практике в силу малых размеров матрицы [math]\displaystyle{ T_{j} }[/math] вычисление соответствующих величин производится непосредственно в теле основного цикла, что позволяет сразу оценить достигнутую точность вычислений.

Схема последовательной реализации алгоритма

Алгоритм итерационный, на каждой итерации выполняется вычисление очередного столбца матрицы [math]\displaystyle{ Q }[/math], а также вычисление элементов очередной пары ( диагонального и околодиагонального ) элементов матрицы [math]\displaystyle{ T }[/math] с использованием значений столбца матрицы [math]\displaystyle{ Q }[/math], полученного на предыдущей итерации и значения околодиагонального элемента матрицы [math]\displaystyle{ T }[/math] с предыдущей итерации. Вектор [math]\displaystyle{ z }[/math] носит вспомогательный характер. Коэффициенты [math]\displaystyle{ \alpha_{j} }[/math] соответствуют диагональным элементам матрицы [math]\displaystyle{ T_{j} }[/math], коэффициенты [math]\displaystyle{ \beta_{j} }[/math] – наддиагональным и поддиагональным элементам той же матрицы. Далее приводится пример псевдокода. По окончании итераций вычислеяются собственные значения и собственные векторы матрицы [math]\displaystyle{ T_{j} }[/math], что в псевдокоде не отражается ( т.к. это отдельный алгоритм ).

q0 - нулевой вектор
beta_0 = 0
foreach (j = 1 .. k ) 
{
     z = A * qj
     alpha_j = qj * z 
     z = z – alpha_j * qj – beta_(j-1) * q(j – 1)
     beta_j = ||z||
     if ( beta_j == 0 )
     {
         break // Все ненулевые собственные значения найдены. Выход может быть досрочным.
     }
     else 
     {
         q(j + 1) = z/beta_j
     }
}

Вычислить собственные значения и собственные векторы симметричной трехдиагональной матрицы Tj наиболее подходящим методом.
Полученный вектор Lj есть искомые собственные значения.

Последовательная сложность алгоритма

Все дальнейшие выкладки верны для наиболее быстрого последовательного варианта выполнения указываемых операций.

  • Умножение квадратной матрицы порядка [math]\displaystyle{ n }[/math] на вектор длины [math]\displaystyle{ n }[/math] и наоборот требует по [math]\displaystyle{ n^2 }[/math] умножений и сложений.
  • Перемножение векторов длины [math]\displaystyle{ n }[/math] требует по [math]\displaystyle{ n }[/math] умножений и сложений.
  • Поэлементное сложение векторов длины [math]\displaystyle{ n }[/math] требует [math]\displaystyle{ n }[/math] сложений.
  • Умножение вектора длины [math]\displaystyle{ n }[/math] на число требует [math]\displaystyle{ n }[/math] умножений.
  • Нахождение квадратичной нормы вектора длины [math]\displaystyle{ n }[/math] требует по [math]\displaystyle{ n }[/math] умножений и сложений, а также одну операцию извлечения квадратного корня.
  • Вычисление собственных значений матрицы порядка [math]\displaystyle{ k }[/math] QR-алгоритмом требует [math]\displaystyle{ O(k^2) }[/math] операций, вычисление также и собственных векторов требует примерно [math]\displaystyle{ 6k ^ 3 }[/math], то есть [math]\displaystyle{ O(k^3) }[/math] операций; при использовании метода «Разделяй-и-властвуй» для вычисления собственных значений и векторов аналогичной матрицы в среднем затрачивается [math]\displaystyle{ O(k^{2}) }[/math] операций.

Таким образом, для выполнения одной итерации метода Ланцоща требуется 1 операция вычисления квадратного корня, [math]\displaystyle{ n }[/math] умножений, а также по [math]\displaystyle{ n ^ 2 + n + 2n + n }[/math] сложений и умножений, а также суммарно [math]\displaystyle{ O(k ^ 3) }[/math] операций, требуемых для поиска собственных значений и собственных векторов матрицы [math]\displaystyle{ T_{j} }[/math]. То есть последовательная сложность алгоритма Ланцоша составляет [math]\displaystyle{ O(n ^ 2) + O(k ^ 3) }[/math]. Это, очевидно, меньше, чем [math]\displaystyle{ O(n ^ 3) }[/math] операций, требуемых в алгоритмах вычисления всех собственных значений произвольных симметричных матриц, в чём и заключается выгода метода Ланцоша.

Информационный граф

Информационный граф алгоритма, определяемый в [2] требует следующего замечания: подразумевается, что, например, умножение квадратной матрицы на вектор распараллеливается на [math]\displaystyle{ n }[/math] потоков, где [math]\displaystyle{ n }[/math] - порядок матрицы, а не на [math]\displaystyle{ n\log{n} }[/math] потоков, чего можно было бы достичь, используя суммирование сдваиванием. Это допущение аналогично допущению из статьи Умножение матрицы на вектор и Это же допущение будет использовано и при оценке ресурса параллелизма алгоритма. Приводится граф без отображения входных и выходных данных.

Ресурс параллелизма алгоритма

Каждая итерация алгоритма Ланцоша выполняется строго последовательно. Однако внутри итерации возможно распараллеливание алгоритма.

  • Умножение квадратной матрицы порядка [math]\displaystyle{ n }[/math] на вектор длины [math]\displaystyle{ n }[/math] требует последовательного выполнения [math]\displaystyle{ n }[/math] ярусов умножений и сложений.
  • Все остальные операции в рамках одной итерации, ведущие к вычислению матрицы [math]\displaystyle{ T_{j} }[/math] выполняются строго последовательно. При этом вычисление значений векторов может быть выполнено за 1 ярус умножений / сложений, а вычисление чисел - за [math]\displaystyle{ \log{n} }[/math] таких операций.
  • Ресурс параллелизма алгоритма вычисления собственных значений зависит от используемого алгоритма и рассматривается в соответствующей статье.

Таким образом, при классификации по ширине ЯПФ алгоритм обладает линейной сложностью. В случае классификации по высоте ЯПФ алгоритм также имеет линейную сложность.

Входные и выходные данные алгоритма

Входные данные: квадратная матрица [math]\displaystyle{ A }[/math] ( элементы [math]\displaystyle{ a_{ij} }[/math] ), вектор [math]\displaystyle{ b }[/math], число [math]\displaystyle{ k }[/math]
Объём входных данных: [math]\displaystyle{ n^2 + n + 1 }[/math]
Выходные данные: вектор [math]\displaystyle{ L }[/math], матрица [math]\displaystyle{ E }[/math] ( элементы [math]\displaystyle{ e_{pq} }[/math] )
Объём выходных данных: [math]\displaystyle{ k + kn }[/math]

Свойства алгоритма

В случае неограниченности ресурсов соотношение последовательной и параллельной сложности алгоритма Ланцоща по сумме всех итераций представляет собой [math]\displaystyle{ k ^ 3 + kn ^ 2 }[/math] к [math]\displaystyle{ X + kn }[/math], где [math]\displaystyle{ X }[/math] - параллельная сложность алгоритма, используемого для вычисления собственных значений. В случае использования метода вычисления собственных значений с линейной сложностью при классисифкации по высоте ЯПФ это соотношение будет равно [math]\displaystyle{ (k ^ 2 + n ^ 2) / (k + n) }[/math].

Алгоритм Ланцоша не является полностью детерминированным в том смысле, что возможно выполнение числа итераций алгоритма, меньшего, чем заданное ( из-за того, что вычислены все ненулевые собственные значения матрицы [math]\displaystyle{ A }[/math] ).

Важное свойство метода Ланцоша состоит в том, что первыми в матрице [math]\displaystyle{ T_{j} }[/math] появляются собственные значения с максимальной величиной по модулю. Таким образом, метод особенно хорошо подходит для вычисления собственных значений матрицы [math]\displaystyle{ A }[/math], находящихся на краях её спектра.

Масштабируемость алгоритма и его реализации

Для проверки масштабируемости алгоритма из реализации была исключена непосредственно задача поиска собственных значений матрицы [math]\displaystyle{ T_{j} }[/math] на каждой итерации, так как это является предметом отдельных статей (QR-алгоритм, метод «Разделяй-и-властвуй», итерации Арнольди и.т.д.). Таким образом, проверяемая на масштабируемость задача сводится к итерационному вычислению коэффициентов матрицы [math]\displaystyle{ T_{j} }[/math]. Матрица [math]\displaystyle{ A }[/math] в рассматриваемой реализации хранится построчно и построчно же разделяется между процессорами. Также в целях исключения влияния недетерминированности алгоритма этот процесс изменен так, что при вычислении всех ненулевых собственных значений матрицы [math]\displaystyle{ A }[/math] работа алгоритма продолжается над фиктивными данными, пока не будет завершено заранее заданное число итераций. При этом в реализации используется OpenMP для распараллеливания в пределах одного узла.

Набор изменяемых параметров запуска реализации алгоритма и границы значений параметров алгоритма:

  • Число MPI процессов [1 : 200]
  • Число OpenMP нитей [1 : 4] (Запуск с 1 OpenMP нитью производился только для 1 MPI процесса, ускорение замерялось относительно этого запуска).
  • Размерность матрицы [400 : 4000]

Эффективность выполнения реализации алгоритма:

  • Минимальная эффективность - <1% (неактуально, так как в исследовании достигнут предел масштабируемости алгоритма).
  • Максимальная эффективность - ~30% (получается на 2-8 процессов при ~640000 ячеек матрицы на процесс; в случае 8 процессов это входная матрица 1600[math]\displaystyle{ {\cdot} }[/math]1600).

Оценка масштабируемости:

  • По числу процессов - при увеличении числа процессов эффективность уменьшается на всей области рассмотренных значений, но не слишком интенсивно. Это связано с небольшим объёмом пересылок данных, реализованных через достаточно эффективные операции редукции.
  • По размеру задачи - при увеличении размера задачи эффективность вычислений вначале кратковременно возрастает, но затем начинает относительно равномерно убывать на всей рассматриваемой области.
  • По двум направлениям - при рассмотрении увеличения, как вычислительной сложности, так и числа процессов по всей рассмотренной области значений наибольшая эффективность наблюдается при соответствии числа процессов и размера задачи. По этой "диагонали" эффективность вначале кратковременно возрастает, затем начинает убывать.

Интересно, что для разного числа процессоров положительные скачки производительности (зачастую - довольно заметные) имеют место на разных объёмах входных данных.

Далее приводятся графики ускорения программы для разных объёмов входных данных. Ускорение считалось относительно варианта с 1 MPI процессом без дальнейшнего распараллеливания посредством OpenMP. На оси абсцисс отмечается число MPI процессов, число OpenMP нитей во всех случаях равно четырём.

Используемая реализация алгоритма Реализация алгоритма гибридная, использует как MPI версии 2.2 (использование MPI_IN_PLACE), так и OpenMP. Указанный код компилировался с помощью компилятора IBM (mpixlcxx_r) с опцией -qsmp=omp (она включает в себя оптимизацию -O2). Реализация алгоритма полностью собственная и не использует встроенные библиотеки. Каждая "quadcore node" - это 1 узел системы BG/P, содержащий 4 микропроцессорных ядра IBM PowerPC 450 c суммарной пиковой производительностью 13.6 GFLOPS на узел и 2 GB общей памяти с пропускной способностью 13.6 GB/sec.
