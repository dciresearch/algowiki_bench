ЧАСТЬ. Свойства и структура алгоритмов[править]

Общее описание алгоритма[править]

Преобразование Фурье - взаимно однозначное отображение одной функции [math]\displaystyle{ f }[/math] вещественной переменной, называемой таргетным сигналом, с другой функцией [math]\displaystyle{ \hat{f} }[/math] вещественной переменной, называемой образом Фурье, или спектром исходной функции, по формуле:

[math]\displaystyle{ \hat{f}(\omega)=\frac{1}{\sqrt{2\pi}}\int\limits_{-\infty}^{\infty}f(x)e^{-ix\omega}\,dx }[/math]

Дискретное преобразование Фурье, в свою очередь, есть аналог непрерывного преобразования Фурье, но для дискретного сигнала, содержащего [math]\displaystyle{ N }[/math] отсчетов. Широко применяется в цифровой обработке сигналов, теории вероятностей, криптографии и акустике. Преобразование Фурье обратимо, причем обратное преобразование имеет практически ту же форму, что и прямое. Преобразование Фурье имеет сложность [math]\displaystyle{ O(N^2) }[/math], но существует быстрый вариант преобразование Фурье со сложностью [math]\displaystyle{ O(N\log{N}) }[/math]. Такая скорость достигается благодаря применению схемы «разделяй и властвуй». Общий вид преобразования позволяет разделить массив на несколько частей таким образом, что, применяя преобразование Фурье к отдельным его частям и объединяя специальным образом результаты (при помощи поворотных множителей и повторного применения преобразования), получать на выходе образ исходного вектора. Но благодаря разделению массива исходного размера на части суммарная асимптотическая сложность алгоритма уменьшается.

Математическое описание алгоритма[править]

Пусть исходный сигнал имеет значения [math]\displaystyle{ x_n,\quad n = 0,\dots,N-1 }[/math], тогда дискретное прямое преобразование Фурье (ДПФ) имеет вид:

[math]\displaystyle{ X_k = \sum_{n=0}^{N-1}x_ne^{-\frac{2\pi i}{N}kn},\quad k = 0, \dots, N-1 }[/math]

Обозначим [math]\displaystyle{ \varepsilon_{N} = e^{-\frac{2\pi i}{N}} }[/math], тогда ДПФ можно перезаписать в матричной форме:

[math]\displaystyle{ \bar X = A\bar x }[/math]

где матрица [math]\displaystyle{ A = \{\varepsilon_{N}^{(i - 1)(j - 1)}\}_{i,j=1}^{N} }[/math]

Вычислительное ядро алгоритма[править]

Пусть, для простоты [math]\displaystyle{ N = km }[/math], тогда рекурсивная реализация преобразования Фурье, за счет [math]\displaystyle{ {k} }[/math] рекурсий на первом этапе и [math]\displaystyle{ m }[/math] на последнем этапе, имеет суммарную сложность [math]\displaystyle{ O(Nk + Nm + km) = O(N(k + m)) }[/math].

В случае, например [math]\displaystyle{ N = 2^n }[/math] сложность БПФ составляет [math]\displaystyle{ O(N\log{N}) }[/math].

В общем же случае, когда [math]\displaystyle{ N = \prod_{i=1}^np_i }[/math] сложность БПФ составляет [math]\displaystyle{ O(N(\sum_{i=1}^np_i)) }[/math]. Так как рекурсия применяется каждый раз при отщеплении одного множителя, то можно заключить, что глубина рекурсии алгоритма составляет [math]\displaystyle{ O(n) }[/math], где [math]\displaystyle{ n }[/math] — число множителей в факторизации [math]\displaystyle{ N }[/math].

В свою очередь, если число [math]\displaystyle{ N }[/math] не факторизуется в произведение простых множителей (то есть [math]\displaystyle{ N }[/math] — простое число), то данный алгоритм напрямую не применим. На замену ему приходит алгоритм Радера, который в некотором смысле сводит задачу размерности [math]\displaystyle{ N }[/math] к подзадаче задаче размерности [math]\displaystyle{ N\pm 1 }[/math] вычисления свертки, в которой допустимо и увеличение размерности до составных в том числе.

Макроструктура алгоритма[править]

Макроструктура БПФ для случая [math]\displaystyle{ N = km }[/math] описывается рекурсивно:

  1. [math]\displaystyle{ k }[/math] независимых преобразований векторов меньшей размерности [math]\displaystyle{ m }[/math]
  2. Умножение элементов на поворотные коэффициенты ([math]\displaystyle{ N }[/math] умножений)
  3. [math]\displaystyle{ m }[/math] обратных преобразований векторов размерностей [math]\displaystyle{ k }[/math]

Схема реализации последовательного алгоритма[править]

Рекурсивный метод для случая [math]\displaystyle{ N = 2^k }[/math], без оптимизации на C++: 

#include <vector>
#include <complex>

using namespace std;

typedef complex<double> cd;
typedef vector<cd> vcd;

vcd fft(const vcd &as) { 
  int n = as.size();
  if (n == 1) return vcd(1, as[0]);

  vcd w(n); // Calculate roots
  for (int i = 0; i < n; i++) {
    double alpha = 2 * M_PI * i / n;
    w[i] = cd(cos(alpha), sin(alpha));
  }

  vcd A(n / 2), B(n / 2);
  for (int i = 0; i < n / 2; i++) {
    A[i] = as[i * 2];
    B[i] = as[i * 2 + 1];
  }
  vcd Av = fft(A);
  vcd Bv = fft(B);
  vcd res(n);
  for (int i = 0; i < n; i++)
    res[i] =   Av[i % (n / 2)] +
        w[i] * Bv[i % (n / 2)];
  return res;
}

В последовательном варианте можно бороться за улучшение константы сложности, предподсчитав значения соответствующих коэффициентов.

Последовательная сложность алгоритма[править]

Алгоритм состоит из трех этапов, следовательно если [math]\displaystyle{ N = \prod_{i = 1}^np_i }[/math], то общая сложность составляет порядка [math]\displaystyle{ O(N\sum_{i=1}^np_i) }[/math] операций.

Пусть существует некоторое фиксированное число [math]\displaystyle{ P }[/math], такое что:

[math]\displaystyle{ p_i \leq P \quad \forall i = 1...n, }[/math]

тогда, учитывая, что [math]\displaystyle{ n \leq \log_{P}{N} }[/math], сложность алгоритма можно записать в виде [math]\displaystyle{ O(N\log{N}) }[/math].

Ресурс параллелизма алгоритма[править]

В силу независимости всех рекурсивных вызовов и того факта, что путь максимальной длины в графе (так называемый критический путь) имеет порядок [math]\displaystyle{ O(\log{N}) }[/math], можно утверждать, что параллельная сложность алгоритма составит [math]\displaystyle{ O(\log{N}) }[/math].

Замечание: формально основание логарифма на каждом рекурсивном шаге зависит от множителя в факторизации [math]\displaystyle{ N }[/math], потому использована О-символика.

При условии ограниченности количества доступных вычислительных узлов рекомендуется выбирать множители в разложении числа [math]\displaystyle{ N }[/math] близкими к числу доступных узлов, таким образом доступные ресурсы будут использованы максимально эффективно.

Итого алгоритм относится к логарифмическому классу алгоритмов по параллельной сложности.

Входные и выходные данные алгоритма[править]

Входные данные: Чаще всего для обработки сигналов в качестве входных данных для БПФ подается вектор размерности [math]\displaystyle{ N }[/math] вещественных элементов. Но БПФ работает и для случая элементов над комплексным полем. Таким образом, например, можно экономить на количестве применений БПФ в некоторой конкретной задаче путем приведения двух векторов вещественных чисел к одному вектору комплексных чисел с вещественной частью равной первому вектору и комплексной частью равной второму вектору: [math]\displaystyle{ x, y }[/math] - исходные сигналы. Обозначим [math]\displaystyle{ z = x + iy }[/math], а [math]\displaystyle{ F(k, x) }[/math] - это [math]\displaystyle{ k }[/math]-ый коэффициент образа Фурье вектора [math]\displaystyle{ x }[/math]. Тогда:

[math]\displaystyle{ F(k, x) = \frac{F(k, z) + F(k, \bar z)}{2} }[/math]
[math]\displaystyle{ F(k, y) = -i\frac{F(k, z) - F(k, \bar z)}{2} }[/math]

Учитывая, что [math]\displaystyle{ F(k, \bar z) = \overline{F(N - k, z)} }[/math], получаем:

[math]\displaystyle{ F(k, x) = \frac{F(k, z) + \overline{F(N-k, z)}}{2} }[/math]
[math]\displaystyle{ F(k, y) = -i\frac{F(k, z) - \overline{F(N-k,z)}}{2} }[/math]

Такой способ позволяет приблизительно в два раза уменьшить количество вычислений.

Выходные данные: Вектор размерности [math]\displaystyle{ N }[/math] комплексных чисел - спектр исходного сигнала.

Свойства алгоритма[править]

Матрица Вандермонда преобразования [math]\displaystyle{ A = \{e^{-\frac{2\pi i}{N}(i - 1)(j - 1)}\}_{i,j=1}^{N} }[/math] такая, что:

[math]\displaystyle{ A^{-1} = \frac{1}{N}A^* }[/math]

Таким образом обратное преобразование Фурье с точностью до нормирующего множителя и сопряжения элементов матрицы совпадает с прямым.

Масштабируемость алгоритма и его реализации[править]

Все запуски программы[1] проводились на с/к Blue Gene/P с использованием библиотеки Intel MKL.

IBM Blue Gene/P — массивно-параллельная вычислительная система, которая состоит из двух стоек, включающих 2048 четырехъядерных вычислительных узлов, с пиковой производительностью 27,9 терафлопс.

Характеристики системы:

  • две стойки с вычислительными узлами и узлами ввода-вывода
  • 1024 четырехъядерных вычислительных узла в каждой из стоек
  • 16 узлов ввода-вывода в стойке (в текущей конфигурации активны 8, т.е. одна I/O-карта на 128 вычислительных узлов)
  • программирование с использованием MPI, OpenMP/pthreads, POSIX I/O
  • высокая энергоэффективность: ∼ 372 MFlops/W

Вычислительный узел включает в себя четырехъядерный процессор, 2 ГБ общей памяти и сетевые интерфейсы.

Вычислительной узел:

  • четыре микропроцессорных ядра PowerPC 450 (4-way SMP)
  • пиковая производительность: 4 ядра x 3,4 GFlop/sec на ядро = 13,6 GFlop/sec
  • пропускная способность памяти: 13,6 GB/sec
  • 2 ГБ общей памяти
  • 2 x 4 МБ кэш-памяти 2-го уровня (в документации по BG/P носит название L3)
  • легковесное ядро (compute node kernel, CNK), представляющее собой Linux-подобную операционную систему, поддерживающую значительное подмножество Linux-совместимых системных вызовов
  • асинхронные операции межпроцессорных обменов (выполняются параллельно с вычислениями)
  • операции ввода-вывода перенаправляются I/O-картам через сеть коллективных операций

Как видно из графика, эффективность параллельной реализации резко падает с ростом количества используемых процессоров, связано это с увеличением количества накладных расходов.
