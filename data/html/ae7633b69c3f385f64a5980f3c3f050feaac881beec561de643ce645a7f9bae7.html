Свойства и структура алгоритма

Общее описание алгоритма

Алгоритм k средних (k means) – неиерархический[1], итерационный метод кластеризации[2], получивший большую популярность благодаря своей простоте, наглядности реализации и достаточно высокому качеству работы. Был изобретен в 1950-х годах математиком Гуго Штейнгаузом[3] и почти одновременно Стюартом Ллойдом[4]. Особую популярность приобрел после публикации работы МакКуина[5] в 1967.

Алгоритм представляет собой версию EM-алгоритма[6], применяемого также для разделения смеси гауссиан. Основная идея k means заключается в том, что данные произвольно разбиваются на кластеры, после чего итеративно перевычисляется центр масс для каждого кластера, полученного на предыдущем шаге, затем векторы разбиваются на кластеры вновь в соответствии с тем, какой из новых центров оказался ближе по выбранной метрике.

Цель алгоритма заключается в разделении [math]\displaystyle{ n }[/math] наблюдений на [math]\displaystyle{ k }[/math] кластеров таким образом, чтобы каждое наблюдение принадлежало ровно одному кластеру, расположенному на наименьшем расстоянии от наблюдения.

Математическое описание алгоритма

Дано:

  • набор из [math]\displaystyle{ n }[/math] наблюдений [math]\displaystyle{ X=\{\mathbf{x}_1, \mathbf{x}_2, ..., \mathbf{x}_n\}, \mathbf{x}_i \in \mathbb{R}^d, i=\overline{1, n} }[/math];
  • [math]\displaystyle{ k }[/math] - требуемое число кластеров, [math]\displaystyle{ k \in \mathbb{N}, k \leq n }[/math].

Требуется:

Разделить множество наблюдений [math]\displaystyle{ X }[/math] на [math]\displaystyle{ k }[/math] кластеров [math]\displaystyle{ S_1, S_2, ..., S_k }[/math]:

  • [math]\displaystyle{ S_i \cap S_j= \varnothing, \quad i \ne j }[/math]
  • [math]\displaystyle{ \bigcup_{i=1}^{k} S_i = X }[/math]


Действие алгоритма:

Алгоритм k means разбивает набор [math]\displaystyle{ X }[/math] на [math]\displaystyle{ k }[/math] наборов [math]\displaystyle{ S_1, S_2, ..., S_k, }[/math] таким образом, чтобы минимизировать сумму квадратов расстояний от каждой точки кластера до его центра (центр масс кластера). Введем обозначение, [math]\displaystyle{ S=\{S_1, S_2, ..., S_k\} }[/math]. Тогда действие алгоритма k means равносильно поиску:

[math]\displaystyle{ \arg\min_{S} \sum\limits_{i=1}^k \sum\limits_{\mathbf{x} \in S_i} \rho(\mathbf{x}, \mathbf{\mu}_i )^2, }[/math] [math]\displaystyle{ (1) }[/math]

где [math]\displaystyle{ \mathbf{\mu}_i }[/math] – центры кластеров, [math]\displaystyle{ i=\overline{1,k}, \quad \rho(\mathbf{x}, \mathbf{\mu}_i) }[/math] – функция расстояния между [math]\displaystyle{ \mathbf{x} }[/math] и [math]\displaystyle{ \mu_i }[/math]


Шаги алгоритма:

  1. Начальный шаг: инициализация кластеров

    Выбирается произвольное множество точек [math]\displaystyle{ \mu_i, i=\overline{1,k} }[/math], рассматриваемых как начальные центры кластеров: [math]\displaystyle{ \mu_i^{(0)} = \mu_i, \quad i=\overline{1, k} }[/math]

  2. Распределение векторов по кластерам

    Шаг [math]\displaystyle{ t: \forall \mathbf{x}_i \in X, i=\overline{1,n}: \mathbf{x}_i \in S_j \iff j=\arg\min_{k}\rho(\mathbf{x}_i,\mathbf{\mu}_k^{(t-1)})^2 }[/math]

  3. Пересчет центров кластеров

    Шаг [math]\displaystyle{ t: \forall i=\overline{1,k}: \mu_i^{(t)} = \cfrac{1}{|S_i|}\sum_{\mathbf{x}\in S_i}\mathbf{x} }[/math]

  4. Проверка условия останова: 

       if [math]\displaystyle{ \exist i\in \overline{1,k}: \mu_i^{(t)} \ne \mu_i^{(t-1)} }[/math] then
       t = t + 1;
       goto 2;
   else
       stop

Вычислительное ядро алгоритма

Вычислительным ядром являются шаги 2 и 3 приведенного выше алгоритма: распределение векторов по кластерам и пересчет центров кластеров.

Распределение векторов по кластерам предполагает вычисление расстояний между каждым вектором [math]\displaystyle{ \mathbf{x}_i \in X, i= \overline{1,n} }[/math] и центрами кластера [math]\displaystyle{ \mathbf{\mu}_j, j= \overline{1,k} }[/math]. Таким образом, данный шаг предполагает [math]\displaystyle{ kn }[/math] вычислений расстояний между d-мерными векторами.

Пересчет центров кластеров предполагает [math]\displaystyle{ k }[/math] вычислений центров масс [math]\displaystyle{ \mathbf{\mu}_i }[/math] множеств [math]\displaystyle{ S_i, i=\overline{1,k} }[/math] представленных выражением в шаге 3 представленного выше алгоритма.

Макроструктура алгоритма

Инициализация центров масс [math]\displaystyle{ \mu_1, ..., \mu_k }[/math].

Наиболее распространенными являются следующие стратегии:

  • Метод Forgy
    В качестве начальных значений [math]\displaystyle{ \mu_1, ..., \mu_k }[/math] берутся случайно выбранные векторы.
  • Метод случайно разделения (Random Partitioning)
    Для каждого вектора [math]\displaystyle{ \mathbf{x}_i \in X, i=\overline{1, n} }[/math] выбирается случайным образом кластер [math]\displaystyle{ S_1, ..., S_k }[/math], после чего для каждого полученного кластера вычисляются значения [math]\displaystyle{ \mu_1, ..., \mu_k }[/math].


Распределение векторов по кластерам

Для этого шага алгоритма между векторами [math]\displaystyle{ \mathbf{x}_i \in X, i=\overline{1, n} }[/math] и центрами кластеров [math]\displaystyle{ \mu_1, ..., \mu_k }[/math] вычисляются расстояния по формуле (как правило, используется Евлидово расстояние):

[math]\displaystyle{ \mathbf{v}_1, \mathbf{v}_2 \in \mathbb{R}^d, \quad \rho(\mathbf{v}_1, \mathbf{v}_2) = \lVert \mathbf{v}_1- \mathbf{v}_2 \rVert= \sqrt{\sum_{i=1}^{d}(\mathbf{v}_{1,i} - \mathbf{v}_{2,i})^2} }[/math] [math]\displaystyle{ (2) }[/math]


Пересчет центров кластеров

Для этого шага алгоритма производится пересчет центров кластера по формуле вычисления центра масс:

[math]\displaystyle{ \mu = \cfrac{1}{|S|}\sum_{\mathbf{x}\in S}\mathbf{x} }[/math] [math]\displaystyle{ (3) }[/math]

Схема реализации последовательного алгоритма

algorithm k-means is
    1. Инициализировать центры кластеров [math]\displaystyle{ \mathbf{\mu}_i^{(1)}, i=\overline{1,k} }[/math]
    2. [math]\displaystyle{ t \leftarrow 1 }[/math]
    3. Распределение по кластерам

       [math]\displaystyle{ S_i^{(t)}=\{\mathbf{x}_p: \lVert\mathbf{x}_p-\mathbf{\mu}_i^{(t)}\rVert^2 \leq \lVert\mathbf{x}_p-\mathbf{\mu}_j^{(t)}\rVert^2 \quad \forall j=\overline{1,k}\}, }[/math]

       где каждый вектор [math]\displaystyle{ \mathbf{x}_p }[/math] соотносится единственному кластеру [math]\displaystyle{ S^{(t)} }[/math]
    4. Обновление центров кластеров

       [math]\displaystyle{ \mathbf{\mu}_i^{(t+1)} = \frac{1}{|S^{(t)}_i|} \sum_{\mathbf{x}_j \in S^{(t)}_i} \mathbf{x}_j  }[/math]

    5. if [math]\displaystyle{ \exist i \in \overline{1,k}: \mathbf{\mu}_i^{(t+1)} \ne \mathbf{\mu}_i^{(t)} }[/math] then
           t = t + 1;
           goto 3;
       else
           stop

Последовательная сложность алгоритма

Обозначим [math]\displaystyle{ \Theta_{\rm centroid}^{d, m} }[/math] временную сложность вычисления центорида кластера, число элементов которого равна [math]\displaystyle{ m }[/math], в d-мерном пространстве.

Аналогично [math]\displaystyle{ \Theta_{\rm distance}^d }[/math] – временная сложность вычисления расстояния между двумя d-мерными векторами.

Сложность шага инициализации [math]\displaystyle{ k }[/math] кластеров мощности [math]\displaystyle{ m }[/math] в d-мерном пространстве – [math]\displaystyle{ \Theta_{\rm init}^{k, d, m} }[/math]

  • Стратерия Forgy: вычисления не требуются, [math]\displaystyle{ \Theta_{\rm init}^{k, d, m} = 0 }[/math]
  • Стратегия случайного разбиения: вычисление центров [math]\displaystyle{ k }[/math] кластеров, [math]\displaystyle{ \Theta_{\rm init}^{k, d, m} = k \cdot \Theta_{\rm centroid}^{d, m}, m \le n }[/math]

Cложность шага распределения d мерных векторов по [math]\displaystyle{ k }[/math] кластерам – [math]\displaystyle{ \Theta_{\rm distribute}^{k, d} }[/math]

На этом шаге для каждого вектора [math]\displaystyle{ \mathbf{x}_i \in X, i=\overline{1, n} }[/math] вычисляется k расстояний до центров кластеров [math]\displaystyle{ \mathbf{\mu}_1, ...\mathbf{\mu}_k }[/math]

[math]\displaystyle{ \Theta_{\rm distribute}^{k, d} = n \cdot k \cdot \Theta_{\rm distance}^d }[/math]

Сложность шага пересчета центров [math]\displaystyle{ k }[/math] кластеров размера [math]\displaystyle{ m }[/math] в d-мерном пространстве – [math]\displaystyle{ \Theta_{\rm recenter}^{k, d, m} }[/math]

На этом шаге вычисляется [math]\displaystyle{ k }[/math] центров кластеров [math]\displaystyle{ \mathbf{\mu}_1, ...\mathbf{\mu}_k }[/math]

[math]\displaystyle{ \Theta_{\rm recenter}^{k, d, m} = k \cdot \Theta_{\rm centroid}^{d, m} }[/math]

Рассчитаем [math]\displaystyle{ \Theta_{\rm centroid}^{d, m} }[/math] для кластера, число элементов которого равно [math]\displaystyle{ m }[/math]

[math]\displaystyle{ \Theta_{\rm centroid}^{d, m} }[/math] = [math]\displaystyle{ m \cdot d }[/math] сложений + [math]\displaystyle{ d }[/math] делений

Рассчитаем [math]\displaystyle{ \Theta_{\rm distance}^d }[/math] в соответствие с формулой [math]\displaystyle{ (2) }[/math]

[math]\displaystyle{ \Theta_{\rm distance}^d }[/math] = [math]\displaystyle{ d }[/math] вычитаний + [math]\displaystyle{ d }[/math] умножений + [math]\displaystyle{ (d-1) }[/math] сложение

Предположим, что алгоритм сошелся за [math]\displaystyle{ i }[/math] итераций, тогда временная сложность алгоритма [math]\displaystyle{ \Theta_{\rm k-means}^{d, n} }[/math]

[math]\displaystyle{ \Theta_{\rm k-means}^{d, n} \le \Theta_{\rm init}^{k, d, n} + i(\Theta_{\rm distribute}^{k, d} + \Theta_{\rm recenter}^{k, d, n}) }[/math]

Операции сложения/вычитания:

[math]\displaystyle{ \Theta_{\rm k-means}^{d, n} \le knd+ i(kn(2d-1) + knd) = knd+ i(kn(3d-1)) \thicksim O(ikdn) }[/math]

Операции умножения/деления:

[math]\displaystyle{ \Theta_{\rm k-means}^{d, n} \le kd + i(knd + kd) = kd + ikd(n+1) \thicksim O(ikdn) }[/math]

Получаем, что временная сложность алгоритма k means кластеризации [math]\displaystyle{ n }[/math] d-мерных векторов на [math]\displaystyle{ k }[/math] кластеров за [math]\displaystyle{ i }[/math] итераций:

[math]\displaystyle{ \Theta_{\rm k-means}^{d, n} \thicksim O(ikdn) }[/math]

Информационный граф

Рассмотрим информационный граф алгоритма. Алгоритм k means начинается с этапа инициализации, после которого следуют итерации, на каждой из которых выполняется два последовательных шага (см. "Схема реализации последовательного алгоритма"):

  • распределение векторов по кластерам
  • перерасчет центров кластеров

Поскольку основная часть вычислений приходится на шаги итераций, распишем информационные графы данных шагов.


Распределение векторов по кластерам

Информационный граф шага распределения векторов по кластерам представлен на рисунке 1. Исходами данного графа является исходные векторы [math]\displaystyle{ \mathbf{x}_1, ..., \mathbf{x}_n }[/math], а также центры кластеров [math]\displaystyle{ \mathbf{\mu}_1, ... \mathbf{\mu}_k }[/math], вычисленные ранее (на шаге инициализации, если рассматривается первая итерация алгоритма, или на шаге пересчета центров кластеров предыдущей итерации в противном случае). Каждая пара векторов данных [math]\displaystyle{ \mathbf{x}_i, i=\overline{1,n} }[/math] и центров кластера [math]\displaystyle{ \mathbf{\mu}_j, j=\overline{1, k} }[/math] : ([math]\displaystyle{ \mathbf{x}_i }[/math], [math]\displaystyle{ \mathbf{\mu}_j }[/math]) подаются на независимые узлы "d" вычисления расстояния между векторами (более подробная схема вычисления расстояния представлена далее, рисунок 2). Далее узлы вычисления расстояния "d", соответствующие одному и тому же исходному вектору [math]\displaystyle{ \mathbf{x}_i }[/math] передаются на один узел "m", где далее происходит вычисление новой метки кластера для каждого вектора [math]\displaystyle{ \mathbf{x}_i }[/math] (берется кластер с минимальным результатом вычисления расстояния). На выходе графа выдаются метки кластеров , [math]\displaystyle{ L_1, ..., L_n }[/math], такие что [math]\displaystyle{ \forall \mathbf{x}_i, i=\overline{1, n}, \mathbf{x}_i \in S_j \Leftrightarrow L_i = j }[/math].


Вычисление расстояния между векторами

Подробная схема вычисления расстояния между векторами [math]\displaystyle{ \mathbf{x}_i, \mathbf{\mu}_j }[/math] представлена на рисунке 2. Как показано на графе, узел вычисления расстояния между векторами "d" состоит из шага взятия разности между векторами (узел "[math]\displaystyle{ - }[/math]") и взятия нормы получившегося вектора разности (узел "[math]\displaystyle{ ||\cdot||^2 }[/math]"). Более подробно, вычисление расстояния между векторами [math]\displaystyle{ \mathbf{x}_i = {x_{i1,}, ...,{x_{in}}}, \mathbf{\mu}_j = {\mu_{j1}, ...,\mu_{jn}} }[/math] может быть представлено как вычисление разности между каждой парой компонент [math]\displaystyle{ (x_{iz}, \mu_{jz}), z=\overline{1, d} }[/math] (узел "[math]\displaystyle{ - }[/math]"), далее возведение в квадрат для каждого узла "[math]\displaystyle{ - }[/math]" (узел "[math]\displaystyle{ ()^2 }[/math]") и суммирования выходов всех узлов "[math]\displaystyle{ ()^2 }[/math]" (узел "[math]\displaystyle{ + }[/math]").

Пересчет центров кластеров

Информационный граф шага пересчета центров кластеров представлен на рисунке 3. Исходами данного графа является исходные векторы [math]\displaystyle{ \mathbf{x}_1, ..., \mathbf{x}_n }[/math], а также им соответствующие метки кластера, [math]\displaystyle{ L_1, ..., L_n }[/math], такие что [math]\displaystyle{ \forall x_i, i=\overline{1, n}, \mathbf{x}_i \in S_j \Leftrightarrow L_i = j }[/math], вычисленные на этапе распределения векторов по кластерам. Все векторы [math]\displaystyle{ \mathbf{x}_1, ..., \mathbf{x}_n }[/math] подаются в узлы [math]\displaystyle{ +_1, ...+_k }[/math], каждый узел [math]\displaystyle{ +_m, m = \overline{1,k} }[/math] соответствует операции сложения векторов кластера с номером [math]\displaystyle{ m }[/math]. Метки кластера [math]\displaystyle{ L_1, ..., L_n }[/math] также совместно передаются на узлы [math]\displaystyle{ S_m, m = \overline{1,k} }[/math], на каждом из которых вычисляется количество векторов в соответствующем кластере (количество меток с соответствующим значением). Далее каждая пара выходов узлов [math]\displaystyle{ +_m }[/math] и [math]\displaystyle{ S_m }[/math] подается на узел "[math]\displaystyle{ / }[/math]", где производится деление суммы векторов кластера на количество элементов в нем. Значения, вычисленные на узлах "[math]\displaystyle{ / }[/math]", присваиваются новым центрам кластеров (выходные значения графа).

Ресурс параллелизма алгоритма

Работа алгоритма состоит из [math]\displaystyle{ i }[/math] итераций, в каждой из которых происходит распределение d-мерных векторов по [math]\displaystyle{ k }[/math] кластерам, а также пересчет центров кластеров в d-мерном пространстве. В шаге распределения d-мерных векторов по [math]\displaystyle{ k }[/math] кластерам расстояния между вектором и центрами кластеров вычисляются независимо (отсутствуют информационные зависимости). Центры масс кластеров также пересчитываются независимо друг от друга. Таким образом, имеет место массовый параллелизм. Вычислим параллельную сложность [math]\displaystyle{ \Psi_* }[/math] каждого из шагов, а также параллельную сложность всего алгоритма, [math]\displaystyle{ \Psi_{\rm k-means} }[/math]. Будем исходить из предположения, что может быть использовано любое необходимое число потоков.


Распределение d-мерных векторов по [math]\displaystyle{ k }[/math] кластерам

Поскольку на данном шаге для каждой пары векторов [math]\displaystyle{ \mathbf{x}_i, i=\overline{1,n} }[/math] и [math]\displaystyle{ \mathbf{\mu}_j, j=\overline{1,k} }[/math] операции вычисления расстояния не зависят друг от друга, они могут выполняться параллельно. Тогда, разделив все вычисление расстояний на [math]\displaystyle{ n }[/math] потоков, получим, что в каждом потоке будет выполняться только одна операция вычисления расстояния между векторами размерности d. При этом каждому вычислительному потоку передаются координаты центров всех кластеров [math]\displaystyle{ \mathbf{\mu}_1, ..., \mathbf{\mu}_k }[/math]. Таким образом, параллельная сложность данного шага определяется сложностью параллельной операции вычисления расстояния между d-мерными векторами, [math]\displaystyle{ \Psi_{\rm distance}^d }[/math] и сложностью определения наиболее близкого кластера (паралельное взятие минимума по расстояниям), [math]\displaystyle{ \Psi_{\rm min}^k }[/math]. Для оценки [math]\displaystyle{ \Psi_{\rm distance}^d }[/math] воспользуемся параллельной реализацией нахождения частичной суммы элементов массива путем сдваивания. Аналогично, [math]\displaystyle{ \Psi_{\rm min}^k = log(k) }[/math]. В результате, [math]\displaystyle{ \Psi_{\rm distance}^d = O(log(d)) }[/math]. Таким образом:

[math]\displaystyle{ \Psi_{\rm distribute}^{k, d} = \Psi_{\rm distance}^d + \Psi_{\rm min}^k = O(log(d))+O(log(k)) = O(log(kd)) }[/math]


Пересчет центров кластеров в d-мерном пространстве

Поскольку на данном шаге для каждого из [math]\displaystyle{ k }[/math] кластеров центр масс может быть вычислен независимо, данные операции могут быть выполнены в отдельных потоках. Таким образом, параллельная сложность данного шага, [math]\displaystyle{ \Psi_{\rm recenter}^{k, d} }[/math], будет определяться параллельной сложностью вычисления одного центра масс кластера размера [math]\displaystyle{ m }[/math], [math]\displaystyle{ \Psi_{\rm recenter}^{k, d} }[/math], а так как [math]\displaystyle{ m \le n \Rightarrow \Psi_{\rm recenter}^{d, m} \le \Psi_{\rm recenter}^{d, n} }[/math]. Сложность вычисления центра масс кластера d-мерных векторов размера n аналогично предыдущим вычислениям равна [math]\displaystyle{ O(log(n)) }[/math]. Тогда:

[math]\displaystyle{ \Psi_{\rm recenter}^{k, d} \le \Psi_{\rm recenter}^{d, n} = O(log(n)) }[/math]


Общая параллельная сложность алгоритма

На каждой итерации необходимо обновление центров кластеров, которые будут использованы на следующей итерации. Таким образом, итерационный процесс выполняется последовательно[7]. Тогда, поскольку сложность каждой итерации определяется [math]\displaystyle{ \Psi_{\rm distribute}^{k, d} }[/math] и [math]\displaystyle{ \Psi_{\rm recenter} }[/math], сложность всего алгоритма, [math]\displaystyle{ \Psi_{\rm k-means} }[/math] в предположении, что было сделано [math]\displaystyle{ i }[/math] операций определяется выражением

[math]\displaystyle{ \Psi_{\rm k-means} \approx i \cdot (\Psi_{\rm distribute}^{k, d} + \Psi_{\rm recenter}^{k, d}) \le i \cdot O(log(kdn)) }[/math]

Входные и выходные данные алгоритма

Входные данные

  • Матрица из [math]\displaystyle{ n \cdot d }[/math] элементов [math]\displaystyle{ x_{i, j} \in \mathbb{R}, i=\overline{1, n}, j=\overline{1, d} }[/math]– координат векторов (наблюдений).
  • Целое положительное число [math]\displaystyle{ k, k \le n }[/math] – количество кластеров.

Объем входных данных
[math]\displaystyle{ 1 }[/math] целое число + [math]\displaystyle{ n \cdot d }[/math] вещественных чисел (при условии, что координаты – вещественные числа).

Выходные данные
[math]\displaystyle{ n }[/math] целых положительных чисел [math]\displaystyle{ L_1, ..., L_n }[/math]– номера кластеров, соотвествующие каждому вектору (при условии, что нумерация кластеров начинается с [math]\displaystyle{ 1 }[/math]).

Объем выходных данных
[math]\displaystyle{ n }[/math] целых положительных чисел.

Свойства алгоритма

Вычислительная мощность

Вычислительная мощность алгоритма k means равна [math]\displaystyle{ \frac{ikdn}{nd} = ki }[/math], где [math]\displaystyle{ k }[/math] – число кластеров, [math]\displaystyle{ i }[/math] – число итераций алгоритма.

Детерминированность и Устойчивость

Алгоритм k means является итерационным. Количество итераций алгоритма в общем случае не фиксируется и зависит от начального расположения объектов в пространстве, параметра [math]\displaystyle{ k }[/math], а также от начального приближения центров кластеров, [math]\displaystyle{ \mu_1, ..., \mu_k }[/math]. В результате этого может варьироваться результат работы алгоритма. При неудачном выборе начальных параметров итерационный процесс может сойтись к локальному оптимуму[8]. По этим причинам алгоритм не является ни детермирированным, ни устойчивым.

Соотношение последовательной и параллельной сложности алгоритма

[math]\displaystyle{ \frac{\Theta_{\rm k-means}}{\Psi_{\rm k-means}} = \frac{O(ikdn)}{O(i \cdot log(kdn))} }[/math]


Сильные стороны алгоритма:

  • Сравнительно высокая эффективность при простоте реализации
  • Высокое качество кластеризации
  • Возможность распараллеливания
  • Существование множества модификаций

Недостатки алгоритма[9]:

  • Количество кластеров является параметром алгоритма

  • Чувствительность к начальным условиям

    Инициализация центров кластеров в значительной степени влияет на результат кластеризации.

  • Чувствительность к выбросам и шумам

    Выбросы, далекие от центров настоящих кластеров, все равно учитываются при вычислении их центров.

  • Возможность сходимости к локальному оптимуму

    Итеративный подход не дает гарантии сходимости к оптимальному решению.

  • Использование понятия "среднего"

    Алгоритм неприменим к данным, для которых не определено понятие "среднего", например, категориальным данным.

Масштабируемость алгоритма и его реализации

Исследование масштабируемости параллельной реализации алгоритма k means проводилось на суперкомпьютере "Ломоносов"[10] Суперкомпьютерного комплекса Московского университета. Алгоритм реализован на языке C с использованием средств MPI. Для исследования масштабируемости проводилось множество запусков программы с разным значением параметра (количество векторов для кластеризации), а также с различным числом процессоров. Фиксировались результаты запусков – время работы [math]\displaystyle{ t }[/math] и количество произведенных итераций алгоритма [math]\displaystyle{ i }[/math].

Параметры запусков для экспериментальной оценки:

  • Значения количества векторов [math]\displaystyle{ n }[/math]: 20'000, 30'000, 50'000, 100'000, 200'000, 300'000, 500'000, 700'000, 1'000'000, 1'500'000, 2'000'000.
  • Значения количества процессоров [math]\displaystyle{ p }[/math]: 1, 8, 16, 32, 64, 128, 160, 192, 224, 256, 288, 320, 352, 384, 416, 448, 480, 512.
  • Значение количества кластеров [math]\displaystyle{ k }[/math]: 100.
  • Значение размерности векторов [math]\displaystyle{ d }[/math]: 10.


Для проведения экспериментов были сгенерированы нормально распределенные псевдослучайные данные (с использованием Python библиотеки scikit-learn): 

from sklearn.datasets import make_classification
X1, Y1 = make_classification(n_features=10, n_redundant=2, n_informative=8,
                             n_clusters_per_class=1, n_classes=100,
                             n_samples=2000000)


Для заданной конфигурации эксперимента ([math]\displaystyle{ n, d, p, k }[/math]) и полученных результатов ([math]\displaystyle{ t, i }[/math]) производительность и эффективность реализации расчитывались по формулам:

  • [math]\displaystyle{ {\rm Performance} = \frac{N_{\rm k-means}^{d, n}}{t}\ \ (FLOPS), }[/math]

где [math]\displaystyle{ N_{\rm k-means}^{d, n} }[/math] – точное число операций с плавающей точкой (операции с памятью, а также целочисленные операции не учитывались), вычисленное в соответствие с разделом "Последовательная сложность алгоритма";

  • [math]\displaystyle{ {\rm Efficiency} = \frac{100 \cdot {\rm Performance}}{{\rm Performance}_{\rm Peak}^{p}}\ \ (%), }[/math]

где [math]\displaystyle{ {\rm Performance}_{\rm Peak}^{p} }[/math] – пиковая производительность суперкомпьютера при [math]\displaystyle{ p }[/math] процессорах, вычисленная согласно спецификациям Intel® XEON® X5670[11].


Графики зависимости производительности и эффективности параллельной реализации k means от числа векторов для кластеризации ([math]\displaystyle{ n }[/math]) и числа процессоров ([math]\displaystyle{ p }[/math]) представлены на рисунках 4 и 5 соответственно.

В результате экспериментальной оценки были получены следующие оценки эффективности реализации:

  • Минимальное значение: 0.000409 % достигается при [math]\displaystyle{ n=20'000, p=480 }[/math]
  • Максимальное значение: 0.741119 % достигается при [math]\displaystyle{ n=300'000, p=1 }[/math]

Оценки масштабируемости реализации алгоритма k means:

  • По числу процессоров: -0.002683 – эффективность убывает с ростом числа процессоров. Данный результат вызван ростом накладных расходов для обеспечения параллельного выполнения алгоритма.
  • По размеру задачи: 0.002779 – эффективность растет с ростом числа векторов. Данный результат вызван тем, что при увеличении размера задачи, количество вычислений растет по сравнению с временем, затрачиваемым на пересылку данных.
  • Общая оценка: -0.000058 – можно сделать вывод, что в целом эффективность реализации незначительно уменьшается с ростом размера задачи и числа процессоров.

Динамические характеристики и эффективность реализации алгоритма

Выводы для классов архитектур

В однопоточном режиме на наборах данных, представляющих практический интерес (порядка нескольких десятков тысяч векторов и выше), время работы алгоритма неприемлемо велико. Благодаря свойству массового параллелизма должно наблюдаться значительное ускорение алгоритма на многоядерных архитектурах (Intel Xeon), а также на графических процессорах, даже на мобильных вычислительных системах (ноутбуках), оснащенных видеокартой. Также алгоритм k means будет демонстрировать значительное ускорение на сверхмощных вычислительных комплексах (суперкомпьютерах, системах облачных вычислений[12]).

На сегодняшний день существует множество реализаций алгоритма k means, в частности, направленных на оптимизацию параллельной работы на различных архитектурах[13][14][15]. Предлагается множество адаптаций алгоритма под конкретные архитектуры. Например, авторы работы[16] производят перерасчет центров кластеров на этапе распределения векторов по кластерам.

    2. Программное обеспечение, созданное для операционных систем Windows, предоставляющее инструменты статистического и пространственного анализа для решения задачи картирования преступности.

    3. Высокоуровневый высокопроизводительный свободный язык программирования с динамической типизацией, созданный для математических вычислений, содержит реализацию k-means.

    5. Написанная на C++ свободная система для математических вычислений, использующая совместимый с MATLAB язык высокого уровня, содержит реализацию k-means.

    6. Распределенная реализация k-means содержится в библиотеке Mlib для работы с алгоритмами машинного обучения, взаимодействующая с Python библиотекой NumPy и библиотека R.

    7. MATLAB-подобная библиотека для языка программирования Lua с открытым исходным кодом, предоставляет большое количество алгоритмов для глубинного обучения и научных расчётов.   8. Accord.NET
    9. C# реализация алгоритмов k-means, k-means++, k-modes.
  9. OpenCV
    10. Написанная на С++ библиотека, направленная в основном на решение задач компьютерного зрения. Содержит реализацию k-means.
  10. MLPACK
    11. Масштабируемая С++ библиотека для работы с алгоритмами машинного обучения, содержит реализацию k-means.
  11. SciPy
    12. Библиотека Python, содержит множество реализаций k-means.
  12. scikit-learn
    13. Библиотека Python, содержит множество реализаций k-means.
  13. R
    14. Язык программирования для статистической обработки данных и работы с графикой, а также свободная программная среда вычислений с открытым исходным кодом в рамках проекта GNU, содержит три реализации k-means.
  14. ELKI
    15. Java фреймворк, содержащий реализацию k-means, а также множество других алгоритмов кластеризации.
